# Safety Sentinel

React and TypeScript front-end prototype for a safety dashboard with incident reporting and emergency-contact sections. The project uses Vite and includes a `supabase/` directory for backend-related material.

## Run locally

```bash
npm install
npm run dev
```

This README describes the interface present in the repository; it does not verify that incident submissions, emergency contacts, authentication, or database integration are production-ready. Do not rely on this prototype as an emergency-response service.
